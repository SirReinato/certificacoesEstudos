# Instruções para agentes

Antes de explorar ou alterar o projeto, leia [`contextoIa/README.md`](contextoIa/README.md).

Use esse documento como mapa inicial, mas confirme detalhes no código quando a tarefa depender deles. Ao concluir uma mudança que afete arquitetura, funcionalidades, rotas, dados, integrações, configuração ou comandos, atualize também o contexto em `contextoIa/README.md`, mantendo-o conciso e fiel ao projeto.
